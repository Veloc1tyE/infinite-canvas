# Infinite Canvas

A game from the [Age of Wonders](https://www.ageofwonders.org) essays. You are one small light, carrying light from where it is abundant to where it has not yet reached. Eleven movements, one for each essay.

**Play:** [ageofwonders.org/game](https://www.ageofwonders.org/game/), or take a build from the [latest release](../../releases/latest).

| Platform | File |
|---|---|
| macOS (Apple Silicon and Intel) | `InfiniteCanvas-macos.zip` |
| Windows (x64) | `InfiniteCanvas-windows-x64.zip` |
| Linux (x86_64) | `InfiniteCanvas-linux-x86_64.tar.gz` |

Needs a graphics driver with OpenGL 4.1. Move with the pointer, WASD or a stick; hold with the mouse, space or A; F for fullscreen, Esc to pause.

The builds are not code-signed. On macOS, right-click the app and choose Open the first time. On Windows, choose More info, then Run anyway.
